# GameFocus Brand Identity

## Icon Design

### Visual Elements
- **Primary Shape**: Game controller silhouette
- **Secondary Shape**: Focus target/concentric rings
- **Color Palette**: 
  - Electric Green (Primary): `#00FF94` (Neon)
  - Electric Blue (Secondary): `#00D1FF`
  - Dark Background: `#0B0E11` / `#15191D`

### Design Language
- Minimal geometric style
- Modern and premium aesthetic
- Recognizable at small sizes
- Android 12+ adaptive icon compatible

### Assets Created
- `ic_launcher_foreground.xml` - Vector adaptive icon (controller + focus rings)
- `ic_launcher_background.xml` - Dark background circle
- `splash_logo.xml` - Larger version for splash screen
- `logo_small.xml` - 48dp version for UI headers
- `ic_notification.xml` - Monochrome notification icon

### Usage
- Launcher Icon: Adaptive icon (all mipmap folders)
- Splash Screen: `splash_logo.xml`
- Dashboard Header: `logo_small.xml`
- Notifications: `ic_notification.xml`

### Theme Integration
- All UI screens use the neon color palette
- Dark background (`#0B0E11`) throughout
- Primary action color: Neon green
- Secondary accents: Electric blue
